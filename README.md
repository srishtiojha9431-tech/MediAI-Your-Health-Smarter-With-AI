# Medi AI 🩺

### Your Health. Smarter with AI.

## 📖 About the Project

**Medi AI** is a responsive healthcare assistant website designed to make healthcare management easier, smarter, and more accessible. It helps users organize medical information, understand symptoms, track health measurements, explore doctors, and manage consultations through a user-friendly dashboard.

## 🔗 GitHub Repository

[**Medi AI – Your Health, Smarter with AI**](https://github.com/srishtiojha9431-tech/MediAI-Your-Health-Smarter-With-AI)

## ✨ Key Features

- **Dashboard:** Overview of health statistics and activities.
- **AI Health Check:** Enter symptoms and health details to generate a health summary.
- **Health Tracking:** Record and monitor health measurements.
- **Medical Records:** Organize medical information.
- **Find a Doctor:** Explore doctor profiles and specialties.
- **Consultations:** View upcoming and previous consultations.
- **Settings:** Manage user profiles and preferences.
- **Multilingual Support:** English, Hindi, and Gujarati.
- **Responsive Design:** Supports desktop, tablet, and mobile devices.

## 🚀 Getting Started

**1. Clone the repository**

```
git clone https://github.com/srishtiojha9431-tech/MediAI-Your-Health-Smarter-With-AI.git
```

**2. Open the project folder**

```
cd MediAI-Your-Health-Smarter-With-AI
```

**3. Run the website**

Open `welcome.html` in your browser or use the VS Code Live Server extension.
